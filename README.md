# VERITAS (Vertex Ensured Reporting & Integrity Transformation Automation Suite) - Streamlit Prototype

This repository contains the source code for a high-fidelity Streamlit prototype of the VERITAS application. VERITAS is designed as a central platform for automated data QC, regulatory reporting, and ensuring data integrity for pre-clinical research at Vertex.

## Core Philosophy

- **Compliance by Design:** Built with 21 CFR Part 11 and GxP principles as a foundation.
- **User-Centric Automation:** Empowers scientists and engineers by automating repetitive tasks.
- **Single Source of Truth (SSOT):** Aims to integrate disparate data sources into one reliable platform.

## Features Demonstrated in this Prototype

1.  **Role-Based Command Center:** A central dashboard with tailored views for DTE Leadership, Scientists/Study Directors, and QC Analysts.
2.  **Data Ingestion Gateway:** A simulated workflow for uploading and validating raw data files.
3.  **Automated QC Engine:** An interface to configure and run data quality rules, including statistical and ML-based checks.
4.  **Regulatory Report Assembler:** A module to automatically generate formatted reports from approved, QC'd data.
5.  **Compliance & Audit Hub:** Tools for ensuring inspection readiness, including an immutable audit trail and a visual data lineage tracer.
